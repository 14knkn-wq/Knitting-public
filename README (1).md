# Knitting

編み物に必要な計算と制作記録を支援する、Spring Boot製のWebアプリケーションです。

> [!NOTE]
> 本プロジェクトは現在、設計・開発途中です。本READMEに記載している機能は、特記がない限り実装予定の内容であり、現時点では未実装です。未確定の仕様は、今後の設計・実装に合わせて更新します。

## プロジェクト概要

「Knitting」は、編み図で指定された糸と異なる糸を使う際の目数・段数調整や、複数の糸を組み合わせる際の概算、制作中の作品管理を支援するWebアプリケーションです。

就職活動用のポートフォリオとして、Spring Bootを学習しながら開発します。単なる学習用アプリにとどめず、実際に編み物をする人が便利に使えることを目指します。

## 開発目的

- 編み図と異なる糸を使う際に必要となる目数・段数の計算を支援する
- 2本取りや引き揃えを行う際の糸の太さと針号数の目安を確認できるようにする
- 制作中の作品、目数、段数、進捗、メモをまとめて管理できるようにする
- Spring Bootを用いたWebアプリケーションの設計・実装経験を、採用担当者などの第三者に分かりやすく示す

## 解決したい課題

- 編み図で指定された糸と手元の糸でゲージが異なる場合、必要な目数・段数を手作業で換算する必要がある
- 2本取りや引き揃えを試す際、組み合わせ後の糸の太さや適した針号数を判断しにくい
- 複数の作品について、現在の目数・段数や制作メモを個別に管理する手間がかかる

## 予定している主要機能

### 1. ゲージ・目数・段数調整

編み図の指定ゲージ、元の目数・段数、実際に使用する糸で測ったゲージを入力し、変更後の目数・段数の目安を計算します。

計算結果の丸め方など、詳細な計算仕様は要検討です。

### 2. 2本取り・引き揃え計算

糸1本ごとの重量（g）と長さ（m）をもとに、最大2本を組み合わせた場合の概算値を計算します。

- 同じ糸を2本使用する「2本取り」
- 異なる糸を組み合わせる「引き揃え」
- 組み合わせ後の換算重量・長さ
- 推定される糸の太さ
- 推奨棒針号数
- 推奨かぎ針号数

素材・撚り・毛羽立ちなどは考慮しないため、結果はあくまで目安です。画面上には、概算であることと試し編みを推奨する旨を表示する予定です。初期バージョンでは3本以上の組み合わせには対応しません。

### 3. 作品管理

作品名、使用糸、使用針、目数、現在の段数、目標段数、制作ステータスを作品ごとに保存し、登録・一覧表示・詳細表示・編集・削除を行えるようにする予定です。

### 4. 目数・段数カウンター

作品ごとに、現在の目数や段数を「＋」「－」などの操作で変更できる機能を予定しています。現在の段数と目標段数をもとにした進捗率表示も検討しています。

### 5. 制作メモ

作品ごとに制作メモを残せる機能を検討しています。段数カウンターとの関連付け方法は要検討です。

### 6. ユーザー機能

将来的に、ユーザー登録、ログイン、ログアウト、自分の作品のみを管理する機能を実装する予定です。認証方式などの詳細は未定です。
