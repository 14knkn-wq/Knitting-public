## 1. システム全体

### 1.1 システム概要

Knittingは、編み物に必要な計算と制作記録を支援するSpring Boot製Webアプリケーションです。

ログインしなくても、ゲージ・目数・段数調整、2本取り・引き揃え計算、簡易カウンター、毛糸・推奨針号数対応表を利用できます。ユーザー登録・ログイン後は、本人の作品を登録し、制作中・完成の状態、目数・段数、制作メモ、完成日等を作品ごとに管理できます。

### 1.2 開発目的

- 編み図と実測ゲージが異なる場合の換算作業を支援する
- 2本取り・引き揃え後の毛糸の太さと推奨針号数の目安を示す
- 制作中・完成作品と制作情報を一元管理できるようにする
- 一時的な目数・段数のカウント機能を、登録不要で利用できるようにする
- Spring Bootを用いた設計・実装経験を示すポートフォリオとする

### 1.3 対象ユーザー

- 編み図と異なる糸・針を使用したい人
- 2本取り・引き揃えを試したい人
- 作品ごとの目数・段数や制作メモを記録したい人
- 制作中作品と完成作品を分けて管理したい人
- ユーザー登録をせず、計算機能や簡易カウンターだけを利用したい人

### 1.4 設計対象範囲

本書では、次の範囲を基本設計の対象とします。

- ログイン状態による利用可能機能の違い
- 機能と画面の構成
- 主要な画面遷移
- 認証・ユーザー登録時のユーザー向け動作
- 作品情報、一覧、カウンター、制作メモ、日時の扱い
- 編み物支援機能の入力・出力・基本計算
- 共通ナビゲーション、入力チェック、保存方式
- システムが保持する主要情報

未ログイン状態で次の画面へアクセスしようとした場合は、ログイン画面へ移動します。

- 作品登録
- 作品詳細
- 制作中一覧

ログイン画面には、次の案内を表示します。

> この機能を利用するにはログインしてください。

アクセス制御にはSpring Securityを使用します。通常のログイン必須画面は案内付きログイン画面へ移動し、作品詳細の非同期保存中に認証状態が失われた場合は画面遷移せず保存を停止して再ログインを案内します。本人作品の判定は作品IDとログインユーザーを組み合わせて行い、存在しない作品と他ユーザーの作品は同じ404として扱います。

## 6. トップ画面

### 6.1 未ログイン時

未ログイン時は、ログインやユーザー登録を強制せず、次の内容を表示します。

- Knittingのアプリ名と概要
- ゲージ・目数・段数調整への入口
- 2本取り・引き揃え計算への入口
- 簡易カウンターへの入口
- 対応表への入口
- ユーザー登録への入口
- ログインへの入口

ログイン後用の共通ナビゲーションは表示しません。ヘッダー左側に文字ロゴ「Knitting」、右側にログイン・ユーザー登録への入口を表示し、ハンバーガーメニューは使用しません。

### 6.2 ログイン後

ログイン後トップでは、本人の制作中作品を主要コンテンツとして表示します。

- 制作中作品を最終更新日時が新しい順に表示する
- 最新4作品を表示する
- 作品カードには作品写真、作品名、目数、段数を表示する
- 表示した作品から作品詳細へ移動できる
- 共通ナビゲーションとは別に、作品登録への入口を設ける
- 公開機能も引き続き利用できる

PCでは作品カードを2列×2行、スマートフォンでは1列で表示します。具体的なカード寸法・配色等は詳細デザイン・実装時に決定します。

## 7. 認証・ユーザー

### 7.1 ユーザー登録

| 項目 | 条件 |
| --- | --- |
| メールアドレス | 必須。メールアドレス形式。小文字へ正規化して保存。重複不可 |
| ユーザー名 | 必須。4～20文字。半角英数字。重複不可 |
| パスワード | 必須。8～64文字。特定の文字種は必須としない |
| パスワード（確認） | 必須。パスワードと一致すること |

- 入力エラーは項目ごとに表示する
- エラーがある間は登録できない
- パスワードと確認用パスワードの表示・非表示を切り替えられる
- 登録成功後は自動ログインしない
- 登録完了の案内を表示してログイン画面へ移動する
- 初期実装ではパスワード再設定機能を設けない
- 平文パスワードと確認用パスワードは保存せず、ハッシュ化済みの認証情報だけを保持する

ユーザー名は前後空白を除去し、入力時の大文字・小文字表記を保持します。重複判定とログイン時は大文字・小文字を区別しません。メールアドレスは前後空白を除去して小文字へ正規化します。パスワードは印字可能なASCII文字を使用し、前後空白の除去や正規化は行いません。登録時にはローカルのPassword Blocklistを用いて推測されやすいパスワードを拒否します。

### 7.2 ログイン

- ユーザー名とパスワードを使用する
- ユーザー名は大文字・小文字を区別せず照合する
- メールアドレスは初期実装のログインIDに使用しない
- ユーザー名・パスワードは必須入力とする
- 未入力項目がある場合は項目ごとに案内し、ログイン操作を行えないようにする
- 認証失敗時は「ユーザー名またはパスワードが正しくありません」という趣旨の共通メッセージを表示する
- 認証失敗の原因がユーザー名かパスワードかを個別に通知しない
- パスワードの表示・非表示を切り替えられるようにする
- ログイン成功後はログイン後トップへ移動する

### 7.3 自動ログイン

- ユーザーが自動ログインを利用するか選択できる
- 自動ログインの初期状態はOFFとする
- 選択した場合は30日間ログイン状態を保持する
- 保持期間内は、ブラウザを閉じた後も原則として再入力なしで利用できる
- 選択しない場合は30日間の自動ログインを使用しない

自動ログインにはSpring Securityのトークン方式を使用し、専用DBテーブルは追加しません。有効期間は30日とし、利用のたびに期限を延長しません。通常の認証状態はセッションで保持し、セッションの非活動タイムアウトは30分とします。有効な自動ログイン情報がある場合は、セッション終了後も再認証できます。

### 7.4 ログアウト

- ログイン後共通ナビゲーションから実行できる
- 実行前にログアウト確認を表示する
- 現在のログイン状態を終了する
- 自動ログインを利用している場合は、その状態も解除する
- ログアウト後は未ログイントップへ移動する

## 8. 作品管理

### 8.1 作品登録

作品登録はログインユーザー向け機能です。登録する作品は、ログイン中のユーザー本人へ関連付けます。

| 項目 | 必須・任意 | 初期仕様 |
| --- | --- | --- |
| 作品名 | 必須 | 1～50文字。同一ユーザー内で重複可 |
| 作品写真 | 任意 | 1作品につき1枚。未登録時は初期画像を使用 |
| カテゴリー | 必須 | 8種類から1つを選択 |
| 制作ステータス | 必須 | 「制作中」「完成」から選択。初期値は「制作中」 |

カテゴリーは次の8種類です。

- 帽子
- 上衣
- 下衣
- マフラー
- バッグ
- ぬいぐるみ
- 小物
- その他

目数・段数・制作メモは作品登録時には入力せず、登録後の作品詳細で管理します。登録に成功した場合は、登録した作品の作品詳細へ移動します。

初期版では、作品画像の実ファイルを開発環境のファイル領域へ保存し、MySQLには画像への論理参照情報を保持します。保存名はアプリケーションが生成し、JPEG・PNGの実データを検証したうえで、必要に応じて向きの補正・長辺1920pxへの縮小・再エンコードを行います。元画像は10MiB以下、幅・高さ8192px以下とします。写真未登録時は参照情報を持たず、画面側でKnitting共通の初期画像を表示します。本番環境の物理保存先は公開環境決定後に確定します。

### 8.2 作品詳細

作品詳細では、次の情報と操作を提供します。

- 作品名、作品写真、カテゴリーの確認・編集
- 制作ステータスの確認・変更
- 完成日の確認・変更（完成作品の場合）
- 作品専用の目数・段数カウンター
- 制作メモ
- 作品削除
- 遷移元の制作中一覧または完成一覧へ戻る操作
- ログイン後共通ナビゲーション

制作中一覧から作品詳細へ移動する場合は `from=in-progress`、完成一覧から移動する場合は `from=completed` を付けます。有効な `from` がある場合は、作品詳細で制作ステータスを変更しても戻り先と共通ナビゲーションの現在地を遷移元一覧に維持します。`from` がない場合は現在の作品ステータスから戻り先を判定し、不正な値は `from` なしとして扱います。基本情報保存後の再表示でも有効な `from` を引き継ぎます。

### 8.3 作品基本情報の編集

作品名、作品写真、カテゴリーは、通常時は閲覧状態とします。

1. ユーザーが編集操作を行う
2. 作品名、作品写真、カテゴリーを編集可能にする
3. 「保存」または「キャンセル」を選択する
4. 「保存」の場合のみ変更を確定する
5. 「キャンセル」の場合は変更を確定しない

作品写真は変更・削除できます。削除後はKnittingの初期画像へ戻します。作品基本情報の編集中に保存せず画面を離れようとした場合は、未保存変更の確認を表示します。未保存状態でログアウトする場合は、ログアウト確認と未保存警告を1つの確認にまとめます。

### 8.4 作品専用カウンター

| 項目 | 目数 | 段数 |
| --- | --- | --- |
| 初期値 | 0 | 0 |
| 範囲 | 0～9999 | 0～9999 |
| 増減 | 1ずつ | 1ずつ |
| 任意値設定 | 現在値を直接入力 | 現在値を直接入力 |
| 保存 | 自動保存 | 自動保存 |

- 目数と段数を同じ画面に同時表示する
- 0では減少操作、9999では増加操作を行えない
- 全角数字は半角数字として扱う
- 数字以外、小数、負数、9999を超える値は受け付けない
- 値は作品ごとに保持する
- 制作中・完成のどちらでも利用できる

目数・段数は画面上の値を即時に反映し、最後の操作から300ms後に非同期保存します。同じ項目の連続操作では中間値を送らず、最新値を順番に保存します。

### 8.5 制作メモ

- 作品ごとに1つ保持する
- 任意入力とする
- 自由記述形式とする
- 最大1000文字とする
- 制作中・完成のどちらでも編集できる
- 明示的な保存ボタンを設けず、自動保存する

制作メモは最後の入力から1秒間操作がない場合に非同期保存します。1000文字を超えている間は送信せず、範囲内へ戻った後に保存を再開します。

### 8.6 制作ステータス

制作ステータスは次の2種類です。

- 制作中
- 完成

両者は作品詳細で自由に切り替えられ、変更内容は自動保存します。ステータス変更時の確認メッセージは表示しません。完成後も、作品基本情報、作品専用カウンター、制作メモ等を利用できます。

### 8.7 完成日

完成日はユーザーから見て年月日単位で扱います。

| 操作・状態 | 完成日の扱い |
| --- | --- |
| 制作中から完成へ変更 | 変更日を初期値として設定する |
| 登録時から完成 | 登録日を初期値として設定する |
| 完成日を手動変更 | 指定した日付へ変更し、自動保存する |
| 完成から制作中へ戻す | 以前の完成日を現在の完成日として使用しない |
| 再度完成へ変更 | 再完成日を新しい初期値として設定する |

初期実装では、現在の完成日を1つだけ管理し、過去の完成日履歴は管理しません。

制作中の作品では、現在の完成日を表示対象としません。
完成日に未来の日付は設定できません。

### 8.8 最終更新日時

制作中作品の表示順を決めるため、最終更新日時を管理します。少なくとも次の操作を更新として扱います。

- 目数変更
- 段数変更
- 制作メモ変更
- 作品名変更
- 写真変更・削除
- カテゴリー変更
- 制作ステータス変更

作品詳細を閲覧しただけでは最終更新日時を変更しません。また、完成日の手動変更だけ、または同じ値の再送でも最終更新日時を変更しません。日時はAsia/Tokyoを基準としてアプリケーション側から設定します。

### 8.9 作品削除

作品削除は作品詳細から行います。

- 削除前に確認メッセージを表示する
- ユーザーは削除をキャンセルできる
- 削除を確定した場合は、作品と紐づく目数・段数・制作メモ等も削除する
- 削除した作品は復元できない
- 削除後はログイン後トップへ移動する

## 9. 作品一覧

制作中一覧と完成一覧には、次の共通仕様を適用します。

- ログインユーザー本人の作品のみを表示する
- 写真未登録時は初期画像を使用する
- カード全体から対象作品の作品詳細へ移動できる
- 一覧上では編集・削除を行わない

- 1ページ最大10作品とする

- スマートフォンでは1列で表示する

作品名は最大2行で表示し、超える部分は省略します。カードの具体的な寸法、写真の縦横比、省略表示の実装方法、カテゴリー選択欄の寸法等は詳細デザイン・実装時に決定します。

## 10. 編み物支援機能

### 10.1 ゲージ・目数・段数調整

目数計算と段数計算を同じ画面で提供し、それぞれ独立して利用できるようにします。ゲージは10cmあたりで統一し、10cm以外を基準とした入力には対応しません。

#### 入力

| 計算 | 入力項目 | 入力形式 |
| --- | --- | --- |
| 目数 | 指定目ゲージ、実測目ゲージ、元の目数 | ゲージは小数可、元の目数は整数 |
| 段数 | 指定段ゲージ、実測段ゲージ、元の段数 | ゲージは小数可、元の段数は整数 |

#### 計算

- 調整後の目数の計算値 ＝ 元の目数 × 実測目ゲージ ÷ 指定目ゲージ
- 調整後の段数の計算値 ＝ 元の段数 × 実測段ゲージ ÷ 指定段ゲージ

計算途中では端数処理を行いません。最終的な計算値を四捨五入し、調整後の目数・段数を整数で表示します。四捨五入前の計算値も表示します。

#### 入力状態

| 状態 | 動作 |
| --- | --- |
| 必要な3項目がすべて未入力 | その側の計算を行わず、エラーにしない |
| 必要な3項目がすべて正常 | 計算結果を表示する |
| 一部だけ入力 | 不足項目を通知し、その側の計算を行わない |
| 0以下・非数値等 | 入力エラーを通知し、計算しない |

指定ゲージ・実測ゲージは0.01～999.99（小数第2位まで）、元の目数・段数は1～9999の整数とします。計算結果が目安であり、実際に試し編みを行うことを推奨する注意書きを表示します。四捨五入前の計算値は小数部最大5桁で表示し、不要な末尾0は表示しません。

### 10.2 2本取り・引き揃え計算

#### 計算モード

| モード | 入力 |
| --- | --- |
| 2本取り | 1本分の重量（g）・長さ（m）。同じ糸を2本使用したものとして計算する |
| 引き揃え | 糸1・糸2それぞれの重量（g）・長さ（m） |

重量・長さは0.01～99999.99、小数第2位までとします。

2本取りと引き揃えは同一画面内のタブで切り替えます。初期表示は2本取りとし、画面を離れていない間はモードを切り替えても各モードの入力値を保持します。初期実装では3本以上に対応しません。

#### 基本計算

1. 各毛糸について「重量（g）÷長さ（m）」で1mあたりの重量を求める
2. 2本分の1mあたりの重量を合計する
3. 「100÷組み合わせ後の1mあたりの重量」で100gあたりの換算糸長を求める
4. 換算糸長を整数へ四捨五入する
5. 対応表と同じ基準で、毛糸の太さと推奨針号数を判定する

2本取りでは、入力した1本分の1mあたりの重量を2倍して計算します。

#### 出力

- 入力した毛糸の重量・長さ
- 約○m / 100g
- 推定される毛糸の太さ
- 推奨棒針号数
- 推奨かぎ針号数
- 対応表への導線

必要項目の空欄、0、負の値、非数値等がある場合はエラーを通知し、すべて正常になるまで計算できないようにします。

計算後に入力値を変更した場合は直前の結果を残し、再計算が必要であることを案内します。

毛糸の素材、撚り、毛足、糸の構造、メーカー、商品名等は計算に使用しません。結果が重量と長さだけから求めた目安であり、試し編みを推奨する注意書きを表示します。

### 10.3 簡易カウンター

簡易カウンターは、作品専用カウンターとは独立した公開機能です。

| 項目 | 仕様 |
| --- | --- |
| カウンター | 目数・段数を同時表示し、独立して操作する |
| 初期値 | 目数・段数ともに0 |
| 範囲 | 0～9999 |
| 増減 | 1ずつ。0では減少不可、9999では増加不可 |
| 任意値 | 0～9999の現在値を直接入力して設定 |
| 個別リセット | 目数・段数を個別に0へ戻す。確認なし |
| 全体リセット | 目数・段数をまとめて0へ戻す。実行前に確認あり |
| 値の保持 | ページ移動後とブラウザ終了後も保持する |

直接入力された全角数字は半角数字として扱い、数字以外、小数、負数、9999を超える値は受け付けません。目数・段数はブラウザのlocalStorageへ個別に保存し、正常値の確定時に即時更新します。localStorageを利用できない場合もページ内では動作を継続し、保持できない可能性を案内します。簡易カウンターの値をユーザー登録後の作品へ引き継ぐ機能は将来検討事項です。

### 10.4 毛糸・推奨針号数対応表

対応表はログインの有無にかかわらず閲覧できる独立画面です。次の項目を1つの表にまとめます。

- 毛糸の太さ区分
- 100gあたりの長さ
- 推奨棒針号数
- 推奨かぎ針号数

表のヘッダーは、縦スクロール中も列見出しを確認できるよう固定します。スマートフォンでも表形式を維持し、画面幅に収まらない場合は表全体を横スクロールできるようにします。初期実装では、複数表の切り替え、検索、絞り込みを設けません。

対応表は、一般的なウール系ストレートヤーンを基準として次の7区分を表示します。

| 太さ | 100gあたりの長さ | 推奨棒針 | 推奨かぎ針 |
| --- | ---: | --- | --- |
| 極細 | 800m以上 | 0～2号（2.1～2.7mm） | 2/0号（2.0mm） |
| 合細 | 500～799m | 1～3号（2.4～3.0mm） | 2/0～3/0号（2.0～2.3mm） |
| 中細 | 350～499m | 2～4号（2.7～3.3mm） | 2/0～4/0号（2.0～2.5mm） |
| 合太 | 250～349m | 4～6号（3.3～3.9mm） | 4/0～5/0号（2.5～3.0mm） |
| 並太 | 175～249m | 6～8号（3.9～4.5mm） | 5/0～7/0号（3.0～4.0mm） |
| 極太 | 101～174m | 9～11号（4.8～5.4mm） | 8/0～10/0号（5.0～6.0mm） |
| 超極太 | 100m以下 | 12号以上（5.7mm以上） | 10/0号以上（6.0mm以上） |

表示値は目安であり、毛糸の商品表示がある場合はメーカーの推奨情報を優先する旨を表示します。2本取り・引き揃え計算結果から直接移動できるようにします。

## 12. 入力チェック・バリデーションの基本方針

### 12.1 共通方針

- 必須項目の未入力、形式不正、範囲外等を検出する
- 入力エラーは可能な限り該当項目ごとに表示する
- 必要な入力が正常になるまで、登録・ログイン・計算等の確定操作を行えないようにする
- ブラウザ側の検証は操作補助とし、正式な検証はサーバー側で必ず行う

### 12.2 主なチェック内容

| 対象 | 主なチェック |
| --- | --- |
| ユーザー登録 | 必須、メール形式、重複、文字数、使用文字、パスワード一致 |
| ログイン | ユーザー名・パスワードの未入力、認証結果 |
| 作品登録・編集 | 作品名・カテゴリーの必須、JPEG／PNG、10MiB以下、幅・高さ8192px以下等の作品写真条件 |
| ゲージ計算 | 必要項目の不足、ゲージ0.01～999.99・小数第2位まで、元の目数・段数1～9999 |
| 2本取り・引き揃え | 必要項目の不足、重量・長さ0.01～99999.99・小数第2位まで |
| カウンター | 0～9999の整数。全角数字は半角として扱い、数字以外・小数・負数・9999超を禁止 |
| 制作メモ | 1000文字を超える入力を禁止 |

## 13. 保存方式

### 13.1 自動保存と明示的保存

| 情報 | 保存方式 | 基本動作 |
| --- | --- | --- |
| 作品名 | 明示的保存 | 編集後に「保存」で確定。「キャンセル」で破棄 |
| 作品写真 | 明示的保存 | 編集後に「保存」で確定。「キャンセル」で破棄 |
| カテゴリー | 明示的保存 | 編集後に「保存」で確定。「キャンセル」で破棄 |
| 目数 | 自動保存 | 変更時に保存し、別の保存操作を不要とする |
| 段数 | 自動保存 | 変更時に保存し、別の保存操作を不要とする |
| 制作メモ | 自動保存 | 明示的な保存ボタンを設けない |
| 制作ステータス | 自動保存 | 変更時に保存する |
| 完成日 | 自動保存 | 変更時に保存する |

自動保存済みの内容は、画面移動やブラウザの戻る操作を行った場合も保持します。作品基本情報は「保存」前に画面を離れた場合、変更を確定しません。

作品基本情報に未保存変更がある状態で画面を離れる場合は確認を表示します。ログアウトする場合は、ログアウト確認と未保存警告を1つにまとめます。制作メモ等の自動保存完了時は入力欄付近に「保存しました」と表示します。

自動保存は画面遷移を伴わない非同期通信で行います。保存中・保存完了・保存失敗を対象付近へ表示します。同一項目の保存は順番に処理し、別画面との競合時は自動統合・自動再試行を行わず、ページ再読み込みを案内します。サーバーエラーまたは通信失敗時も自動再試行せず、ユーザーが最新の画面値を手動で再試行できるようにします。

### 13.2 簡易カウンターの保持

簡易カウンターは作品情報の自動保存とは別に扱い、目数・段数をブラウザのlocalStorageへ個別に保存します。作品専用カウンターのDB保存とは関連付けません。

## 14. データとして保持する主要情報

本節は、システムが保持する情報を基本設計レベルで示します。初期版のMySQL業務データは `users` と `works` の2テーブルで管理し、`users` 1 : N `works` の関係とします。具体的なカラム、データ型、キー、制約およびインデックスは `04_database-design.md` で定義済みです。

1人のユーザーは0件以上の作品を所有でき、1作品は必ず1人のユーザーに属します。

| 情報群 | 主な情報 |
| --- | --- |
| ユーザー | メールアドレス、ユーザー名、認証に必要なパスワード情報、ユーザー登録日時 |
| 作品 | 所有者、作品名、作品写真、カテゴリー、制作ステータス |
| 制作情報 | 目数、段数、制作メモ、完成日、最終更新日時 |
| 簡易カウンター | 目数、段数 |
| 対応表 | 毛糸の太さ区分、100gあたりの長さ、推奨棒針号数、推奨かぎ針号数 |

作品基本情報と現在の制作情報は、初期版では1件の `works` データとしてまとめて保持し、ログインユーザー本人のデータとして扱います。制作履歴、カウンター履歴、制作メモ履歴および完成日履歴は保持しません。作品画像本体はローカルへ保存し、MySQLには参照情報を保持します。

簡易カウンターは作品専用カウンターと区別し、初期版のMySQL業務データテーブルには含めずlocalStorageで保持します。対応表は専用テーブルを設けず、S-05とS-07が同じアプリケーション内基準を参照します。主要な作品一覧取得を考慮したインデックスは、`04_database-design.md` で定義済みです。

## 15. 非機能・品質に関する基本方針

### 15.1 使用性

- 編み物をするユーザーが入力と結果を理解しやすい構成とする
- PC・スマートフォンの両方で利用できる構成とする
- 作品一覧はPCで2列、スマートフォンで1列とする
- 対応表はスマートフォンでも表形式を維持し、必要に応じて横スクロールできるようにする
- ログイン後はPC・スマートフォンともハンバーガーメニューを使用する
- 計算値や対応表が目安である場合は注意書きを表示する
- 保存方式の違いがユーザーに分かるようにする

### 15.2 正確性・信頼性

- 計算式、四捨五入、境界値に対してテストを行う
- 自動保存した内容が画面移動等で失われないようにする
- 作品一覧の表示対象と並び順を、制作ステータスに応じて正しく分ける

### 15.3 セキュリティ

- 認証後も、ログインユーザー本人の作品だけを閲覧・変更できるようにする
- パスワード、自動ログイン、ログイン状態を安全に扱う
- Spring Securityを使用し、フォームログイン、CSRF対策、セッション管理、30日間の自動ログイン、本人作品のみのアクセス制御を行う
- 平文パスワードを保存せず、Spring Securityの委譲型エンコーダーによるハッシュ化済み情報だけを保持する
- 公開前にログイン・ユーザー登録へのRate Limitを導入し、本番公開ではHTTPSを必須とする

### 15.4 性能・運用

想定利用者数、目標応答時間、同時アクセス数、公開環境、バックアップ、監視、稼働方針は未定です。ポートフォリオとして必要以上に大規模・複雑な構成にはしません。
