## 1. システム全体

### 1.1 システム概要

Knittingは、編み物に必要な計算と制作記録を支援するSpring Boot製Webアプリケーションです。

ログインしなくても、ゲージ・目数・段数調整、2本取り・引き揃え計算、簡易カウンター、毛糸・推奨針号数対応表を利用できます。ユーザー登録・ログイン後は、本人の作品を登録し、制作中・完成の状態、目数・段数、制作メモ、完成日時等を作品ごとに管理できます。

### 1.2 開発目的

- 編み図と実測ゲージが異なる場合の換算作業を支援する
- 2本取り・引き揃え後の毛糸の太さと推奨針号数の目安を示す
- 制作中・完成作品と制作情報を一元管理できるようにする
- 一時的な目数・段数のカウント機能を、登録不要で利用できるようにする
- Spring Bootを用いた設計・実装経験を示すポートフォリオとする

### 1.3 対象ユーザー

- 編み図と異なる糸・針を使用したい人
- 2本取り・引き揃えを試したい人
- 作品ごとの目数・段数や制作メモを記録したい人
- 制作中作品と完成作品を分けて管理したい人
- ユーザー登録をせず、計算機能や簡易カウンターだけを利用したい人

### 1.4 設計対象範囲

本書では、次の範囲を基本設計の対象とします。

- ログイン状態による利用可能機能の違い
- 機能と画面の構成
- 主要な画面遷移
- 認証・ユーザー登録時のユーザー向け動作
- 作品情報、一覧、カウンター、制作メモ、日時の扱い
- 編み物支援機能の入力・出力・基本計算
- 共通ナビゲーション、入力チェック、保存方式
- システムが保持する主要情報

## 6. トップ画面

### 6.1 未ログイン時

未ログイン時は、ログインやユーザー登録を強制せず、次の内容を表示します。

- Knittingのアプリ名と概要
- ゲージ・目数・段数調整への入口
- 2本取り・引き揃え計算への入口
- 簡易カウンターへの入口
- 対応表への入口
- ユーザー登録への入口
- ログインへの入口

ログイン後用の共通ナビゲーションは表示しません。未ログイン時のヘッダー構成、ロゴ、各入口の配置は画面設計時に決定します。

### 6.2 ログイン後

ログイン後トップでは、本人の制作中作品を主要コンテンツとして表示します。

- 制作中作品を最終更新日時が新しい順に表示する
- 表示した作品から作品詳細へ移動できる
- 共通ナビゲーションとは別に、作品登録への入口を設ける
- 公開機能も引き続き利用できる

トップ画面に表示する制作中作品の件数、作品カードの表示項目とデザインは画面設計時に決定します。

## 7. 認証・ユーザー

### 7.1 ユーザー登録

| 項目 | 条件 |
| --- | --- |
| メールアドレス | 必須。メールアドレス形式。重複不可 |
| ユーザー名 | 必須。4～20文字。半角英数字。重複不可 |
| パスワード | 必須。8～64文字。特定の文字種は必須としない |
| パスワード（確認） | 必須。パスワードと一致すること |

- 入力エラーは項目ごとに表示する
- エラーがある間は登録できない
- 登録成功後は自動ログインしない
- 登録完了の案内を表示してログイン画面へ移動する
- 初期実装ではパスワード再設定機能を設けない

ユーザー名の大文字・小文字を区別するかは要検討です。パスワードに使用できる具体的な文字の範囲、検証タイミング、メッセージ文言は詳細設計・画面設計で決定します。

### 7.2 ログイン

- ユーザー名とパスワードを使用する
- メールアドレスは初期実装のログインIDに使用しない
- ユーザー名・パスワードは必須入力とする
- 未入力項目がある場合は項目ごとに案内し、ログイン操作を行えないようにする
- 認証失敗時は「ユーザー名またはパスワードが正しくありません」という趣旨の共通メッセージを表示する
- 認証失敗の原因がユーザー名かパスワードかを個別に通知しない
- パスワードの表示・非表示を切り替えられるようにする
- ログイン成功後はログイン後トップへ移動する

### 7.3 自動ログイン

- ユーザーが自動ログインを利用するか選択できる
- 選択した場合は30日間ログイン状態を保持する
- 保持期間内は、ブラウザを閉じた後も原則として再入力なしで利用できる
- 選択しない場合は30日間の自動ログインを使用しない

30日の起算タイミング、自動ログインでアクセスした際に期間を更新するか、保持方法と安全対策は詳細設計で決定します。

### 7.4 ログアウト

- ログイン後共通ナビゲーションから実行できる
- 現在のログイン状態を終了する
- 自動ログインを利用している場合は、その状態も解除する
- ログアウト後は未ログイントップへ移動する

## 8. 作品管理

### 8.1 作品登録

作品登録はログインユーザー向け機能です。登録する作品は、ログイン中のユーザー本人へ関連付けます。

| 項目 | 必須・任意 | 初期仕様 |
| --- | --- | --- |
| 作品名 | 必須 | 重複可。最大文字数は要検討 |
| 作品写真 | 任意 | 1作品につき1枚。未登録時は初期画像を使用 |
| カテゴリー | 必須 | 8種類から1つを選択 |
| 制作ステータス | 必須 | 「制作中」「完成」から選択 |

カテゴリーは次の8種類です。

- 帽子
- 上衣
- 下衣
- マフラー
- バッグ
- ぬいぐるみ
- 小物
- その他

目数・段数・制作メモは作品登録時には入力せず、登録後の作品詳細で管理します。登録に成功した場合は、登録した作品の作品詳細へ移動します。

### 8.2 作品詳細

作品詳細では、次の情報と操作を提供します。

- 作品名、作品写真、カテゴリーの確認・編集
- 制作ステータスの確認・変更
- 完成日時の確認・変更（完成作品の場合）
- 作品専用の目数・段数カウンター
- 制作メモ
- 作品削除
- 現在の制作ステータスに対応する一覧へ戻る操作
- ログイン後共通ナビゲーション

制作中作品では制作中一覧、完成作品では完成一覧を戻り先とします。作品詳細でステータスを変更した後は、変更後のステータスに対応する一覧を戻り先とします。

### 8.3 作品基本情報の編集

作品名、作品写真、カテゴリーは、通常時は閲覧状態とします。

1. ユーザーが編集操作を行う
2. 作品名、作品写真、カテゴリーを編集可能にする
3. 「保存」または「キャンセル」を選択する
4. 「保存」の場合のみ変更を確定する
5. 「キャンセル」の場合は変更を確定しない

作品写真は変更・削除できます。削除後はKnittingの初期画像へ戻します。保存前に画面を離れようとした場合に警告するかは要検討です。

### 8.4 作品専用カウンター

| 項目 | 目数 | 段数 |
| --- | --- | --- |
| 初期値 | 0 | 0 |
| 範囲 | 0～9999 | 0～9999 |
| 増減 | 1ずつ | 1ずつ |
| 任意値設定 | 0～9999から選択 | 0～9999から選択 |
| 保存 | 自動保存 | 自動保存 |

- 目数と段数を同じ画面に同時表示する
- 0では減少操作、9999では増加操作を行えない
- 値は作品ごとに保持する
- 制作中・完成のどちらでも利用できる

任意値を選択する具体的なUIと、自動保存の具体的な通信・保存方法は後工程で決定します。

### 8.5 制作メモ

- 作品ごとに1つ保持する
- 任意入力とする
- 自由記述形式とする
- 最大1000文字とする
- 制作中・完成のどちらでも編集できる
- 明示的な保存ボタンを設けず、自動保存する

自動保存の具体的なタイミングは詳細設計・実装時に決定します。

### 8.6 制作ステータス

制作ステータスは次の2種類です。

- 制作中
- 完成

両者は作品詳細で自由に切り替えられ、変更内容は自動保存します。ステータス変更時の確認メッセージは表示しません。完成後も、作品基本情報、作品専用カウンター、制作メモ等を利用できます。

### 8.7 完成日時

完成日時はユーザーから見て年月日単位で扱います。

| 操作・状態 | 完成日時の扱い |
| --- | --- |
| 制作中から完成へ変更 | 変更日を初期値として設定する |
| 登録時から完成 | 登録日を初期値として設定する |
| 完成日時を手動変更 | 指定した日付へ変更し、自動保存する |
| 完成から制作中へ戻す | 以前の完成日時を現在の完成日時として使用しない |
| 再度完成へ変更 | 再完成日を新しい初期値として設定する |

初期実装では、現在の完成日時を1つだけ管理し、過去の完成日時履歴は管理しません。

制作中の作品では、現在の完成日時を表示対象としません。

### 8.8 最終更新日時

制作中作品の表示順を決めるため、最終更新日時を管理します。少なくとも次の操作を更新として扱います。

- 目数変更
- 段数変更
- 制作メモ変更
- 作品名変更
- 写真変更・削除
- カテゴリー変更
- 制作ステータス変更

作品詳細を閲覧しただけでは最終更新日時を変更しません。具体的な管理方法は詳細設計時に決定します。

### 8.9 作品削除

作品削除は作品詳細から行います。

- 削除前に確認メッセージを表示する
- ユーザーは削除をキャンセルできる
- 削除を確定した場合は、作品と紐づく目数・段数・制作メモ等も削除する
- 削除した作品は復元できない
- 削除後はログイン後トップへ移動する

## 9. 作品一覧

### 9.1 共通仕様

制作中一覧と完成一覧には、次の共通仕様を適用します。

- ログインユーザー本人の作品のみを表示する
- 各作品を「作品写真＋作品名」のカードとして表示する
- 写真未登録時は初期画像を使用する
- カード全体から対象作品の作品詳細へ移動できる
- 一覧上では編集・削除を行わない
- 「すべて」と8種類のカテゴリーで絞り込める
- カテゴリーを変更した場合は、絞り込み結果の1ページ目を表示する
- 1ページ最大10作品とする
- PCでは2列×5行を基本とする
- 11作品以上の場合は「前へ・ページ番号・次へ」でページを切り替える
- 10作品以下の場合はページ切り替えを表示しなくてもよい
- 通常時は画面内に常設の作品登録ボタンを設けず、共通ナビゲーションを使用する
- 対象作品が0件の場合は、案内と作品登録への入口を表示する

スマートフォンでの列数、作品カードの具体的な形、長い作品名の表示、カテゴリー選択UIは画面設計時に決定します。

## 10. 編み物支援機能

### 10.1 ゲージ・目数・段数調整

目数計算と段数計算を同じ画面で提供し、それぞれ独立して利用できるようにします。ゲージは10cmあたりで統一し、10cm以外を基準とした入力には対応しません。

#### 入力

| 計算 | 入力項目 | 入力形式 |
| --- | --- | --- |
| 目数 | 指定目ゲージ、実測目ゲージ、元の目数 | ゲージは小数可、元の目数は整数 |
| 段数 | 指定段ゲージ、実測段ゲージ、元の段数 | ゲージは小数可、元の段数は整数 |

#### 計算

- 調整後の目数の計算値 ＝ 元の目数 × 実測目ゲージ ÷ 指定目ゲージ
- 調整後の段数の計算値 ＝ 元の段数 × 実測段ゲージ ÷ 指定段ゲージ

計算途中では端数処理を行いません。最終的な計算値を四捨五入し、調整後の目数・段数を整数で表示します。四捨五入前の計算値も表示します。

#### 入力状態

| 状態 | 動作 |
| --- | --- |
| 必要な3項目がすべて未入力 | その側の計算を行わず、エラーにしない |
| 必要な3項目がすべて正常 | 計算結果を表示する |
| 一部だけ入力 | 不足項目を通知し、その側の計算を行わない |
| 0以下・非数値等 | 入力エラーを通知し、計算しない |

計算結果が目安であり、実際に試し編みを行うことを推奨する注意書きを表示します。小数桁数、入力上限、具体的なエラーメッセージは後工程で決定します。

### 10.2 2本取り・引き揃え計算

#### 計算モード

| モード | 入力 |
| --- | --- |
| 2本取り | 1本分の重量（g）・長さ（m）。同じ糸を2本使用したものとして計算する |
| 引き揃え | 糸1・糸2それぞれの重量（g）・長さ（m） |

2本取りと引き揃えは、ラジオボタンではなく画面切り替え方式で利用します。タブ、ボタン等の具体的な切り替えUIは画面設計時に決定します。初期実装では3本以上に対応しません。

#### 基本計算

1. 各毛糸について「重量（g）÷長さ（m）」で1mあたりの重量を求める
2. 2本分の1mあたりの重量を合計する
3. 「100÷組み合わせ後の1mあたりの重量」で100gあたりの換算糸長を求める
4. 換算糸長を整数へ四捨五入する
5. 対応表と同じ基準で、毛糸の太さと推奨針号数を判定する

2本取りでは、入力した1本分の1mあたりの重量を2倍して計算します。

#### 出力

- 入力した毛糸の重量・長さ
- 約○m / 100g
- 推定される毛糸の太さ
- 推奨棒針号数
- 推奨かぎ針号数
- 対応表への導線

必要項目の空欄、0、負の値、非数値等がある場合はエラーを通知し、すべて正常になるまで計算できないようにします。

毛糸の素材、撚り、毛足、糸の構造、メーカー、商品名等は計算に使用しません。結果が重量と長さだけから求めた目安であり、試し編みを推奨する注意書きを表示します。

### 10.3 簡易カウンター

簡易カウンターは、作品専用カウンターとは独立した公開機能です。

| 項目 | 仕様 |
| --- | --- |
| カウンター | 目数・段数を同時表示し、独立して操作する |
| 初期値 | 目数・段数ともに0 |
| 範囲 | 0～9999 |
| 増減 | 1ずつ。0では減少不可、9999では増加不可 |
| 任意値 | 0～9999から数値選択UIで設定 |
| 個別リセット | 目数・段数を個別に0へ戻す。確認なし |
| 全体リセット | 目数・段数をまとめて0へ戻す。実行前に確認あり |
| 値の保持 | ページ移動後とブラウザ終了後も保持する |

値の保存先、保存・読み込みタイミング、数値選択UIは後工程で決定します。簡易カウンターの値をユーザー登録後の作品へ引き継ぐ機能は将来検討事項です。

### 10.4 毛糸・推奨針号数対応表

対応表はログインの有無にかかわらず閲覧できる独立画面です。次の項目を1つの表にまとめます。

- 毛糸の太さ区分
- 100gあたりの長さ
- 推奨棒針号数
- 推奨かぎ針号数

表が画面内に収まらない場合は、スクロールして確認できるようにします。初期実装では、複数表の切り替え、検索、絞り込みを設けません。

具体的な太さ区分、100gあたりのメートル数、推奨針号数、太さ区分の並び順は未確定です。詳細設計または実装前に、一般的な編み物基準やメーカー情報等を調査して決定します。

表示値は目安であり、毛糸の商品表示がある場合はメーカーの推奨情報を優先する旨を表示します。2本取り・引き揃え計算結果から直接移動できるようにします。

## 13. 保存方式

### 13.1 自動保存と明示的保存

| 情報 | 保存方式 | 基本動作 |
| --- | --- | --- |
| 作品名 | 明示的保存 | 編集後に「保存」で確定。「キャンセル」で破棄 |
| 作品写真 | 明示的保存 | 編集後に「保存」で確定。「キャンセル」で破棄 |
| カテゴリー | 明示的保存 | 編集後に「保存」で確定。「キャンセル」で破棄 |
| 目数 | 自動保存 | 変更時に保存し、別の保存操作を不要とする |
| 段数 | 自動保存 | 変更時に保存し、別の保存操作を不要とする |
| 制作メモ | 自動保存 | 明示的な保存ボタンを設けない |
| 制作ステータス | 自動保存 | 変更時に保存する |
| 完成日時 | 自動保存 | 変更時に保存する |

自動保存済みの内容は、画面移動やブラウザの戻る操作を行った場合も保持します。作品基本情報は「保存」前に画面を離れた場合、変更を確定しません。

自動保存の具体的なタイミング・通信方法、保存完了表示、保存失敗時の処理は画面設計・詳細設計で決定します。

### 13.2 簡易カウンターの保持

簡易カウンターは作品情報の自動保存とは別に扱います。ページ移動後とブラウザ終了後も値を保持しますが、保持先と具体的な保存方式は詳細設計・実装時に決定します。

## 15. 非機能・品質に関する基本方針

### 15.1 使用性

- 編み物をするユーザーが入力と結果を理解しやすい構成とする
- PC・スマートフォンの両方で利用できる構成を目指す
- 計算値や対応表が目安である場合は注意書きを表示する
- 保存方式の違いがユーザーに分かるようにする

### 15.2 正確性・信頼性

- 計算式、四捨五入、境界値に対してテストを行う
- 自動保存した内容が画面移動等で失われないようにする
- 作品一覧の表示対象と並び順を、制作ステータスに応じて正しく分ける

### 15.3 セキュリティ

- 認証後も、ログインユーザー本人の作品だけを閲覧・変更できるようにする
- パスワード、自動ログイン、ログイン状態を安全に扱う
- 具体的な認証・認可方式は詳細設計で決定する

### 15.4 性能・運用

想定利用者数、目標応答時間、同時アクセス数、公開環境、バックアップ、監視、稼働方針は未定です。ポートフォリオとして必要以上に大規模・複雑な構成にはしません。
