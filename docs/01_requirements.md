## 1. システム概要

「Knitting」は、Spring Bootを使用して開発する編み物支援Webアプリケーションです。

編み図と実測ゲージの違いに応じた目数・段数調整、2本取り・引き揃え時の毛糸の太さと推奨針号数の概算、簡易カウンターをログインなしで利用できます。ユーザー登録・ログイン後は、作品、制作ステータス、目数・段数、制作メモ等を作品ごとに保存・管理できます。

就職活動用のポートフォリオとして開発しますが、単なる学習用アプリではなく、実際に編み物をする人が便利に使えることを目指します。

## 2. 開発目的

- 編み図と実測ゲージが異なる場合の目数・段数計算を支援する
- 2本取り・引き揃え後の毛糸の太さと推奨針号数を判断するための目安を示す
- 作品ごとの制作状況、目数・段数、制作メモを一元管理できるようにする
- ログインしなくても使える編み物支援機能を提供し、利用開始の負担を抑える
- Spring Bootを用いたWebアプリケーションの設計・実装経験を、採用担当者等の第三者へ分かりやすく示す

## 3. 想定ユーザー

- 編み図で指定された糸・針とは異なる条件で編みたい人
- 2本取りまたは引き揃えを試したい人
- 制作中・完成済みの作品を分けて管理したい人
- 作品ごとの目数・段数や制作メモを記録したい人
- ユーザー登録をせず、計算機能や簡易カウンターだけを利用したい人

ユーザーの年齢、編み物経験、利用端末の具体的な範囲は要検討です。

## 4. 解決したい課題

### 4.1 ゲージの違いによる計算負担

編み図の指定ゲージと実際に使用する糸・針で測定したゲージが異なる場合、同程度の大きさに仕上げるための目数・段数を手作業で換算する必要があります。必要な値を入力することで、調整後の目数・段数を確認できるようにします。

### 4.2 2本取り・引き揃え時の判断

2本の毛糸を組み合わせた場合の太さや適した針号数は判断しにくいため、重量と長さから100gあたりの換算糸長を算出し、毛糸の太さと推奨針号数の目安を表示します。

### 4.3 制作情報の分散

複数の作品を制作する場合、作品情報、制作状態、現在の目数・段数、制作メモ等が分散しやすくなります。これらを作品単位で保存し、制作中作品と完成作品を分けて確認できるようにします。

### 4.4 一時的なカウント手段の不足

作品登録を行わずに目数・段数だけを数えたい場合にも使える簡易カウンターを提供し、ページ移動やブラウザ終了後も値を保持できるようにします。

## 6. 機能要件

以下のチェックボックスは、要件ごとの実装状況を表します。現時点ではすべて未実装です。実装と確認が完了した項目のみ `[x]` へ変更します。

### 6.1 トップ画面

- [ ] 未ログイン時は、Knittingの概要、公開機能、ユーザー登録、ログインへの入口を表示できる
- [ ] 未ログイン時にログインを強制せず、公開機能を利用できる
- [ ] ログイン後は、ログインユーザー本人の制作中作品を表示できる
- [ ] ログイン後トップの制作中作品を最終更新日時が新しい順に表示できる
- [ ] ログイン後トップの作品から対象作品の作品詳細へ移動できる
- [ ] ログイン後トップから作品登録と公開機能へ移動できる

ログイン後トップに表示する制作中作品の件数と具体的な表示項目は、画面設計時に決定します。

### 6.2 ゲージ・目数・段数調整

- [ ] 目数計算と段数計算を同じ機能内で利用できる
- [ ] 目数と段数をそれぞれ独立して計算できる
- [ ] 指定目ゲージ・実測目ゲージ・元の目数から調整後の目数を計算できる
- [ ] 指定段ゲージ・実測段ゲージ・元の段数から調整後の段数を計算できる
- [ ] ゲージはすべて10cmあたりの目数・段数として扱う
- [ ] 指定ゲージと実測ゲージは小数を入力できる
- [ ] 元の目数と元の段数は整数として入力できる
- [ ] 目数側または段数側の3項目がすべて未入力の場合、その側は計算対象外としてエラーにしない
- [ ] 計算に必要な項目の一部だけが入力された場合は、入力不足を通知する
- [ ] 0以下や数値として扱えない値等を入力エラーとして扱う
- [ ] 計算途中では端数処理を行わず、最終結果を四捨五入して整数で表示する
- [ ] 四捨五入前の計算値と、四捨五入後の調整結果を表示する
- [ ] 計算結果が目安であり、試し編みを推奨する旨を表示する

目数と段数の基本計算は、それぞれ次の考え方を使用します。

- 調整後の目数の計算値 ＝ 元の目数 × 実測目ゲージ ÷ 指定目ゲージ
- 調整後の段数の計算値 ＝ 元の段数 × 実測段ゲージ ÷ 指定段ゲージ

ゲージの小数桁数、四捨五入前の表示桁数、入力上限、具体的なエラーメッセージは後工程で決定します。模様編みの倍数等に合わせる自動調整は初期実装の対象外です。

### 6.3 2本取り・引き揃え計算

- [ ] 「2本取り」と「引き揃え」を切り替えて利用できる
- [ ] 2本取りでは、1本分の重量（g）と長さ（m）を入力し、同じ毛糸を2本使用したものとして計算できる
- [ ] 引き揃えでは、異なる2本の毛糸について重量（g）と長さ（m）を個別に入力できる
- [ ] 重量と長さは小数を入力できる
- [ ] 3本以上の組み合わせには対応しない
- [ ] 各毛糸の1mあたりの重量をもとに、組み合わせ後の100gあたりの換算糸長を算出できる
- [ ] 換算糸長を整数へ四捨五入し、「約○m / 100g」と表示できる
- [ ] 換算糸長から推定される毛糸の太さを表示できる
- [ ] 推定した太さに対応する推奨棒針号数・推奨かぎ針号数を表示できる
- [ ] 計算結果から毛糸・推奨針号数対応表へ移動できる
- [ ] 必要項目の空欄、0、負の値、数値として扱えない値等を入力エラーとして扱う
- [ ] 必要な入力値がすべて正常な場合のみ計算できる
- [ ] 重量と長さだけによる目安であることと、試し編みを推奨する注意書きを表示する

毛糸の素材、撚り、毛足、糸の構造、メーカー、商品名等は計算対象としません。毛糸の太さ区分、区分ごとの換算糸長の境界値、推奨針号数は未確定であり、詳細設計または実装前に根拠を調査して決定します。

### 6.4 簡易カウンター

- [ ] ログインの有無にかかわらず利用できる
- [ ] 目数カウンターと段数カウンターを同じ画面に同時表示できる
- [ ] 目数のみ、段数のみ、または両方を利用できる
- [ ] 目数・段数の初期値を0とする
- [ ] 目数・段数をそれぞれ独立して1ずつ増減できる
- [ ] 目数・段数を0～9999の範囲で管理できる
- [ ] 0では減少操作、9999では増加操作を行えない
- [ ] 0～9999の範囲から任意の現在値を設定できる
- [ ] 目数・段数を個別に0へリセットできる
- [ ] 目数・段数をまとめて0へ戻す際は、実行前に確認できる
- [ ] ページ移動後も値を保持できる
- [ ] ブラウザを閉じた後も値を保持し、再度アクセスした際に前回の値から再開できる
- [ ] 作品専用カウンターとは別の機能として扱う

任意の現在値を選択する具体的なUIと、値を保持する技術・保存方法は後工程で決定します。簡易カウンターの値をユーザー登録後の作品へ引き継ぐ機能は、初期実装後の将来検討事項です。

### 6.5 毛糸・推奨針号数対応表

- [ ] ログインの有無にかかわらず閲覧できる
- [ ] 毛糸の太さ区分、100gあたりの長さ、推奨棒針号数、推奨かぎ針号数を1つの表で確認できる
- [ ] 表が画面内に収まらない場合も、スクロールして確認できる
- [ ] 表示値が目安であり、毛糸の商品表示がある場合はメーカーの推奨情報を優先する旨を表示する
- [ ] 2本取り・引き揃え計算結果から直接移動できる

初期実装では対応表を1種類とし、表の切り替え、検索、絞り込みは設けません。太さ区分、100gあたりの具体的な長さ、推奨棒針号数、推奨かぎ針号数、表示順は未確定です。

### 6.6 ユーザー登録

- [ ] メールアドレス、ユーザー名、パスワード、確認用パスワードを入力して登録できる
- [ ] すべての項目を必須入力として扱う
- [ ] メールアドレスの形式を確認し、登録済みメールアドレスの重複を許可しない
- [ ] ユーザー名を4文字以上20文字以下の半角英数字として扱う
- [ ] 登録済みユーザー名の重複を許可しない
- [ ] パスワードを8文字以上64文字以下として扱う
- [ ] パスワードと確認用パスワードの一致を確認する
- [ ] 項目ごとに入力エラーを表示し、エラーがある場合は登録できない
- [ ] 登録完了後は自動ログインせず、登録完了の案内を表示してログイン画面へ移動する

ユーザー名は、半角英字だけ、半角数字だけ、または両方の組み合わせを使用できます。パスワードに特定の文字種を含めることは必須としません。ユーザー名の大文字・小文字を区別するかは要検討です。初期実装ではパスワード再設定機能を設けません。

### 6.7 ログイン・自動ログイン・ログアウト

- [ ] ユーザー名とパスワードでログインできる
- [ ] メールアドレスは初期実装のログインIDとして使用しない
- [ ] 未入力項目がある場合は項目ごとにエラーを表示し、ログインできない
- [ ] 認証失敗時は、原因を個別に特定しない共通メッセージを表示する
- [ ] パスワードの表示・非表示を切り替えられる
- [ ] ログイン成功後はログイン後トップ画面へ移動する
- [ ] ユーザーが自動ログインの利用有無を選択できる
- [ ] 自動ログインを選択した場合は30日間ログイン状態を保持できる
- [ ] ログイン中は共通ナビゲーションからログアウトできる
- [ ] 明示的なログアウト時は自動ログイン状態も解除する
- [ ] ログアウト後は未ログイン状態のトップ画面へ移動する

30日の起算タイミング、利用時の期間更新有無、認証状態を保持する具体的な方法は詳細設計時に決定します。

### 6.8 作品登録

- [ ] ログインユーザーが自分の作品を登録できる
- [ ] 作品名を必須入力として登録でき、同じ作品名の重複を許可する
- [ ] カテゴリーを必須項目として1つ選択できる

- [ ] 制作ステータスを「制作中」または「完成」から選択できる
- [ ] 必須項目にエラーがある場合は項目ごとに通知し、正常になるまで登録できない

初期実装のカテゴリーは「帽子・上衣・下衣・マフラー・バッグ・ぬいぐるみ・小物・その他」とします。目数・段数および制作メモは登録時には入力せず、登録後の作品詳細で管理します。作品名の最大文字数、写真のファイル形式・容量等は後工程で決定します。

- [ ] 目数・段数の初期値を0とする

## 9. 制約事項

- 使用言語はJavaとする
- フレームワークはSpring Bootとする
- 開発にはEclipseを使用する
- バージョン管理にはGitを使用し、GitHubで管理する
- 2本取り・引き揃え計算は重量と長さのみを使用し、素材・撚り・毛足等を考慮しない
- 2本取り・引き揃え計算は最大2本までとし、初期実装では3本以上に対応しない
- 毛糸の太さ、推奨針号数および対応表は目安として提供する
- 対応表の具体的な数値は、根拠を調査するまで確定しない
- 初期実装ではパスワード再設定機能を設けない
- 初期実装では過去の完成日時履歴を管理しない
- 初期実装では計算機能一覧画面を設けない
- 初心者がSpring Bootを学習しながら開発するため、必要以上に大規模・複雑なシステムにはしない
- Java、Spring Boot、Eclipse、Git、GitHub以外の技術は現時点では確定していない
