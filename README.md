# Knitting

編み物に必要な計算と制作記録を支援する、Spring Boot製のWebアプリケーションです。

> [!NOTE]
> 本プロジェクトは、要件定義から詳細設計までを完了し、現在は設計書に基づいて実装を進めています。各機能の実装状況は、本README内の「実装状況」を参照してください。公開環境や具体的な画面装飾等の後工程事項は、決定に合わせて更新します。

## プロジェクト概要

「Knitting」は、編み図で指定された糸と異なる糸を使う際の目数・段数調整、2本取り・引き揃え時の概算、目数・段数のカウント、作品の制作記録を支援するWebアプリケーションです。

就職活動用のポートフォリオとして、Spring Bootを学習しながら開発します。単なる学習用アプリにとどめず、実際に編み物をする人が便利に使えることを目指します。

## 開発目的

- 編み図と異なる糸を使う際に必要となる目数・段数の計算を支援する
- 2本取りや引き揃えを行う際の毛糸の太さと針号数の目安を確認できるようにする
- 作品ごとの目数・段数、制作状況、制作メモをまとめて管理できるようにする
- Spring Bootを用いたWebアプリケーションの設計・実装経験を、採用担当者などの第三者に分かりやすく示す

## 解決したい課題

- 編み図で指定された糸と手元の糸でゲージが異なる場合、必要な目数・段数を手作業で換算する必要がある
- 2本取りや引き揃えを試す際、組み合わせ後の毛糸の太さや適した針号数を判断しにくい
- 編み物中の目数・段数を手軽に数え、途中の値から再開したい
- 複数の作品について、制作状況や現在の目数・段数、制作メモを個別に管理する手間がかかる

## 予定している主要機能

### 1. ゲージ・目数・段数調整

編み図の指定ゲージ、元の目数・段数、実際に使用する糸で測ったゲージを入力し、調整後の目数・段数の目安を計算します。

指定ゲージ・実測ゲージは0.01〜999.99（小数第2位まで）、元の目数・段数は1〜9999の整数として扱います。計算途中では端数処理を行わず、四捨五入前の計算値を小数部最大5桁で表示したうえで、最終結果を四捨五入した整数として表示します。

### 2. 2本取り・引き揃え計算

各毛糸の重量（g）と長さ（m）を入力し、最大2本を組み合わせた場合の概算値を計算します。

- 同じ糸を2本使用する「2本取り」
- 異なる糸を組み合わせる「引き揃え」

各毛糸の「重量÷長さ」から1mあたりの重量を求め、2本分を合計した値から、組み合わせ後の100gあたりの換算糸長を算出します。結果として、次の内容を表示します。

- 入力した各毛糸の重量・長さ
- 100gあたりの換算糸長
- 推定される毛糸の太さ
- 推奨棒針号数
- 推奨かぎ針号数

素材・撚り・毛足・商品名等は計算対象としません。結果はあくまで目安であり、画面上には試し編みを推奨する注意書きを表示します。計算結果から対応表へ移動できる導線を設けます。初期実装では3本以上の組み合わせには対応しません。

### 3. 簡易カウンター

ログインの有無にかかわらず利用できる、作品登録とは独立した目数・段数カウンターです。目数と段数を同時に表示し、それぞれ0〜9999の範囲で「＋」「－」または現在値の直接入力により変更できます。全角数字は半角数字として扱い、数字以外、小数、負数、9999を超える値は受け付けません。

値はブラウザのlocalStorageへ目数・段数を分けて保存し、ページ移動後やブラウザ終了後も保持します。localStorageを利用できない場合もページ内では使用できますが、ページ移動・再読み込み・終了後に値を保持できない可能性がある旨を案内します。

### 4. 毛糸・推奨針号数対応表

毛糸の太さ区分、100gあたりの長さ、推奨棒針号数、推奨かぎ針号数を1つの表へまとめて表示します。

一般的なウール系ストレートヤーンを基準に、「極細」「合細」「中細」「合太」「並太」「極太」「超極太」の7区分と、それぞれの100gあたりの長さ・推奨針を表示します。表示値は目安であり、メーカーの商品表示がある場合はメーカーの推奨情報を優先する旨を表示します。

### 5. 作品管理

ユーザー登録・ログイン後に、自分の作品を登録・管理できるようにします。

作品登録時に扱う主な情報は次のとおりです。

- 作品名（必須・1〜50文字・同一ユーザー内で重複可）
- 作品写真（任意・1作品につき1枚。未登録時は初期画像を使用）
- カテゴリー
- 制作ステータス（制作中・完成）

目数・段数と制作メモは、登録後の作品詳細画面で管理します。作品詳細では、作品名・写真・カテゴリーを「編集」後の保存操作で確定し、目数・段数・制作メモ・制作ステータス・完成日は非同期で自動保存します。基本情報の編集中に保存せず画面を離れる場合は、未保存変更の確認を表示します。自動保存中・完了・失敗を項目付近へ表示し、通信失敗等は自動再試行せずユーザーが再試行できるようにします。

作品は制作ステータスに応じて、制作中一覧または完成一覧に表示します。

- 制作中一覧：最終更新日時が新しい順
- 完成一覧：完成日が新しい順
- カテゴリーによる絞り込み
- 1ページ最大10作品のページネーション
- 制作中作品カード：作品写真・作品名・目数・段数
- 完成作品カード：作品写真・作品名・完成日
- 一覧から作品詳細を表示
- 一覧から作品登録へ移動
- 作品詳細から作品情報を編集
- 作品を削除

カテゴリーは初期実装では「帽子」「上衣」「下衣」「マフラー」「バッグ」「ぬいぐるみ」「小物」「その他」とします。

### 6. 作品専用カウンター・制作メモ

作品詳細画面に目数と段数のカウンターを同時に表示します。初期値は両方0、範囲は0〜9999とし、「＋」「－」で1ずつ変更できるほか、現在値を直接入力できます。全角数字は半角数字として扱い、範囲外の値等は受け付けません。

作品ごとに任意入力・最大1000文字の制作メモを1つ保持します。カウンターと制作メモは、制作中・完成のどちらでも変更でき、自動保存します。

### 7. ユーザー・認証

ユーザー登録、ログイン、自動ログイン、ログアウト、自分の作品のみを管理する機能を備えます。各機能の実装状況は「実装状況」を参照してください。

ユーザー名は4〜20文字の半角英数字とし、重複を許可しません。重複判定とログイン時は大文字・小文字を区別しません。パスワードは8〜64文字とし、特定の文字種を必須としません。

認証・認可にはSpring Securityを使用します。自動ログインはユーザーが利用有無を選択でき、選択した場合はトークン方式で30日間ログイン状態を保持します。利用のたびに期限は延長しません。作品機能では、ログインユーザー本人の作品だけを閲覧・変更・削除できるようにします。

ログイン後の主要画面では、PC・スマートフォンの両方でハンバーガーメニューを使用します。「トップ」「作品を登録」「制作中一覧」「完成一覧」「ゲージ・目数・段数調整」「2本取り・引き揃え計算」「簡易カウンター」「毛糸・推奨針号数対応表」「ログアウト」を区分ごとに一覧表示し、何段階も展開するサブメニューは使用しません。初期実装では計算機能一覧画面を設けません。
